# Cburnett chess pieces

These SVG source files are the `cburnett` piece theme from the open-source
[lichess.org codebase](https://github.com/lichess-org/lila/tree/master/public/piece/cburnett).
They are retained here so the generated PNG assets can be reproduced at other
resolutions. Lichess's repository is distributed under the GNU Affero General
Public License v3.0; see the upstream repository for license and attribution
details.

The application uses the generated `*_modern_64x64.png` and
`*_modern_256x256.png` files in the parent directory at runtime.
